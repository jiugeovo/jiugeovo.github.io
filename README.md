# 刘鹏程个人主页 Demo

一个用于展示个人简介、真实项目和学习方向的响应式个人主页，部署于 GitHub Pages。

## 技术实现

- 使用 HTML 编写页面语义结构和内容模块；
- 使用 CSS 完成栅格布局、响应式适配、颜色系统和交互状态；
- 使用 JavaScript 实现移动端导航、页面内锚点跳转和年份更新；
- 使用 GitHub Pages 部署静态页面。

## 本地运行

直接用浏览器打开 `index.html`，或在项目目录启动静态服务器：

```powershell
python -m http.server 8000
```

然后访问 <http://localhost:8000>。
